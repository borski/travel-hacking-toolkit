# ViajaNet / Decolar

Search [ViajaNet](https://www.viajanet.com.br/) (or [Decolar](https://www.decolar.com/),
same Despegar storefront) for cash flights priced in BRL.

**Why it matters:** for trips starting in Brazil these OTAs regularly show fares the
global sources miss. In testing, a GRU-Toronto Arajet fare at R$ 3,540 appeared
here but not in Kiwi. They also report exactly which bags are included in each
fare, which matters for ultra-low-cost carriers like Arajet that sell
personal-item-only fares.

**No login or key.** The results page calls
`/shop/flights-busquets/api/v1/web/search`, but that request carries a signature
(`h=`) and session ids generated by the page's JavaScript, so it cannot be
called directly. The script loads the public results URL in a real browser
(Patchright) and captures the search response the page fetches for itself.

## Prerequisites

```bash
pip install patchright && patchright install chromium
```

Or Docker (headed via Xvfb):

```bash
docker build -t viajanet skills/viajanet/
```

## When to Use

- Any cash flight search departing Brazil (or arriving there), alongside Kiwi / Skiplagged
- When Arajet, Brazilian LCCs or BRL promos might be the cheapest option
- When baggage matters and you need to know what each fare includes

## When NOT to Use

- **Completing a purchase.** Return prices and the search URL only.
- **Points / award pricing.** Use `azul-pelo-mundo`, `seats-aero` or the airline sites.

## Usage

```bash
# Round trip on ViajaNet
python3 skills/viajanet/scripts/search_viajanet.py \
  --origin GRU --dest YYZ --depart 2027-10-01 --return 2027-10-16 --json

# One-way on Decolar, 2 adults + 1 lap infant
python3 skills/viajanet/scripts/search_viajanet.py --site decolar \
  --origin GRU --dest MAD --depart 2027-11-05 --adults 2 --infants 1 --json

# Docker
docker run --rm viajanet --origin GRU --dest YYZ --depart 2027-10-01 --return 2027-10-16 --json
```

| Flag | Default | Notes |
|------|---------|-------|
| `--site` | `viajanet` | `viajanet` or `decolar`. |
| `--origin` / `--dest` | required | IATA airport codes. |
| `--depart` / `--return` | required / none | `YYYY-MM-DD`; omit `--return` for one-way. |
| `--adults` / `--children` / `--infants` | 1 / 0 / 0 | |
| `--limit` | 20 | Max itineraries, cheapest first. |
| `--retries` | 3 | |
| `--json` | off | Emit JSON. |

## Output

```json
{
  "source": "viajanet",
  "searchUrl": "https://www.viajanet.com.br/shop/flights/results/multioneway/GRU/YYZ/...",
  "count": 10,
  "itineraries": [
    {
      "totalBRL": 3540,
      "fareBRL": 1230,
      "taxesBRL": 2310,
      "validatingCarrier": "DM",
      "airlines": ["DM"],
      "separateTickets": true,
      "clusterType": "VIRTUAL_INTERLINING_2OW",
      "outbound": {
        "departure": "2027-10-01 23:55", "arrival": "2027-10-02 11:40",
        "duration": "12:45", "stops": 1, "via": ["PUJ"],
        "flights": ["DM6021", "DM5802"],
        "bags": {"checked": 0, "carryOn": false, "personalItem": true, "checkedPurchasable": true}
      },
      "inbound": {"...": "same shape"}
    }
  ]
}
```

- **`totalBRL`** is the final price for the whole party, taxes included.
- **`bags`** is per leg. `checked: 0` with `checkedPurchasable: true` means the bag
  is sold as an add-on: tell the user and estimate the extra before comparing fares.
- **`separateTickets: true`** means two one-way tickets (`VIRTUAL_INTERLINING_2OW`).
  A missed connection or schedule change on one ticket is not protected by the other.

## Known fragility

- Round-trip URLs are redirected to `multioneway`. In that mode the first
  search response carries only the outbound leg, so `inbound` can be `null`
  while `totalBRL` is still the full round-trip price. Verified live (Nov 2026)
  on GRU-YYZ: cheapest Arajet R$ 3,540 without a
  checked bag and R$ 4,004 with one.
- The results URL and response shape come from the live site and may change.
  If nothing is captured, repeat the search in a normal browser and compare the
  `/shop/flights-busquets/api/v1/web/search` response with `parse_search`.
- Space searches out; rapid repeats from one IP can be throttled.
